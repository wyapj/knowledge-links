# wyapj 知识链接图谱

这是一个基于 GitHub Star / 相关项目整理的知识地图网页，按照功能、领域和关系将项目连接起来，并为每个项目提供一句话总结。

## 内容结构

- 点状拓扑图：展示项目之间的功能关联
- 项目摘要：每个节点都有中文简介
- 主题分组：AI / LLM、机器人、自动驾驶、工具与学习资源
- 点击交互：选中节点后查看详细介绍和关键关联

## 访问方式

直接打开仓库中的 `index.html` 即可查看页面。若想更自然地预览，可在本地启动静态服务：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 说明

本网页以你在 GitHub 上的关注与 Star 项目为主线，聚焦与 AI、机器人、自动驾驶和学习资源相关的知识网络。它可作为进一步整理研究路线、项目脉络和学习体系的入口。
